# Amine Portfolio

Professional freelance portfolio built with React, Vite, Node.js, Express, and MongoDB.

## Run Locally

```bash
npm install
npm run dev
```

The API expects MongoDB at:

```bash
mongodb://127.0.0.1:27017/amine_portfolio
```

To use another database, copy `.env.example` to `.env` and update `MONGODB_URI`.

## Build

```bash
npm run build
npm start
```
